## 色彩方案

### Terminal主控台

- **背景**：#2c3e50 (深灰色)
- **标签栏背景**：#3a3a3a (更深灰)
- **文本**：#ffffff (白色)
- **按钮-OK**：#4CAF50 (绿色)
- **按钮-Error**：#F44336 (红色)
- **状态-运行**：#FFC107 (黄色)
- **卡片背景**：#34495e (稍浅灰)
- **边框**：#1a252f (最深灰)

### Station操作台

- **背景**：#ffffff (白色)
- **顶部栏**：#f5f5f5 (浅灰)
- **文本**：#333333 (深灰)
- **按钮-Connect**：#4CAF50 (绿色)
- **按钮-Disconnect**：#f44336 (红色)

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+O | 连接 |
| Ctrl+D | 断开 |
| Ctrl+, | 配置 |
| Ctrl+L | 查看日志 |
| Ctrl+Q | 退出 |
| F1 | 帮助 |
