## 🔌 物理连接方案详解

### 场景1：现有条件（推荐）

**硬件:**

- 1台PC
- 1台PLC

**拓扑:**

```
PC (192.168.33.100)
├─ Terminal Server (进程1)
│  └─→ S7协议 → PLC (192.168.33.1)
├─ Station 1 (进程2)
├─ Station 2 (进程3)
├─ Station 3 (进程4)
└─ Station 4 (进程5)

所有进程通过 localhost:5555 通信
```

**优势:**

- ✅ 成本最低
- ✅ 部署最简单
- ✅ 本地调试快
- ✅ 故障诊断容易

**网络配置:**

```
┌─────────────────────┐
│ PC 网卡设置         │
├─────────────────────┤
│ IP: 192.168.33.100  │
│ 掩码: 255.255.255.0 │
│ 网关: 192.168.33.1  │
└─────────────────────┘
         ↕
  RJ45网线连接
         ↕
┌─────────────────────┐
│ PLC                 │
├─────────────────────┤
│ IP: 192.168.33.1    │
│ Port: 102 (S7)      │
└─────────────────────┘
```

---

### 场景2：小型部署（2-3台PC）

**硬件:**

- 1台中央PC（Terminal）
- 2-3台操作台PC（Stations）

**拓扑:**

```
中央PC (192.168.1.100:5555)
├─ Terminal Server (Port 102 → PLC)
└─ [TCP通信] ←─ 操作台PC 1 (192.168.1.101)
              ←─ 操作台PC 2 (192.168.1.102)
              ←─ 操作台PC 3 (192.168.1.103)

所有PC在同一局域网
```

**网络配置:**

```
中央PC:
  IP: 192.168.1.100
  启动: WaterTestSystem.exe --mode terminal --bind 0.0.0.0

操作台1:
  IP: 192.168.1.101
  启动: WaterTestSystem.exe --mode station --id 1 --host 192.168.1.100

操作台2:
  IP: 192.168.1.102
  启动: WaterTestSystem.exe --mode station --id 2 --host 192.168.1.100

操作台3:
  IP: 192.168.1.103
  启动: WaterTestSystem.exe --mode station --id 3 --host 192.168.1.100
```

**优势:**

- ✓ 操作台位置灵活
- ✓ 中央集中管理
- ✓ 可靠性好
- ✗ 需要网络交换机

---

### 场景3：大型部署（4台操作台PC）

**硬件:**

- 1台中央PC（Terminal + PLC驱动）
- 4台操作台PC（Stations）
- 网络交换机

**拓扑:**

```
           ┌──────────────────────────┐
           │   网络交换机(Switch)      │
           ├──────────────────────────┤
    ┌──────┴──────┬──────┬──────┬────┘────┐
    │             │      │      │         │
    ▼             ▼      ▼      ▼         ▼
 ┌──────┐    ┌──────┐┌────┐┌────┐   ┌──────┐
 │中央PC│←──→│Op-1  ││Op-2││Op-3│   │ PLC  │
 │Term  │    └──────┘└────┘└────┘   └──────┘
 └──────┘           
   :5555  192.168.1.101-104     192.168.1.1

Internet可选 (远程管理)
```

**启动脚本:**

```bash
# 中央PC上
start "" WaterTestSystem.exe --mode terminal --bind 0.0.0.0

# 操作台PC上分别运行
WaterTestSystem.exe --mode station --id 1 --host 192.168.1.100
WaterTestSystem.exe --mode station --id 2 --host 192.168.1.100
WaterTestSystem.exe --mode station --id 3 --host 192.168.1.100
WaterTestSystem.exe --mode station --id 4 --host 192.168.1.100
```

## ⚡ 启动顺序很关键

### ✅ 正确的启动顺序

```
1️⃣ 启动 Terminal Server
   └─ 开始轮询PLC
   └─ 监听5555端口

2️⃣ 等待2-3秒

3️⃣ 启动 Station 1
   └─ 连接到localhost:5555
   └─ 接收数据并显示

4️⃣ 启动 Station 2-4
   └─ 按相同方式连接
```

**使用脚本自动处理：**

```bash
launch_system.bat → 选择3 → 一键启动
```

### ❌ 错误的做法

```
✗ 先启动Stations再启动Terminal
  → Stations无法连接，报错

✗ 多个Terminal同时启动
  → 端口冲突，其中一个失败

✗ PLC掉线后再启动Terminal
  → Terminal启动失败或频繁重试
```

## 💡 故障排查

### 问题1：Station连不上Terminal

**检查顺序:**

1. Terminal是否启动了？

   ```bash
   tasklist | find "WaterTestSystem"
   ```

2. 端口5555是否监听？

   ```bash
   netstat -an | find ":5555"
   ```

3. PLC是否连接？

   ```bash
   ping 192.168.33.1
   ```

### 问题2：PLC无法连接

1. IP配置是否正确？

   ```bash
   ipconfig
   # 查看是否为 192.168.33.xxx
   ```

2. 网线是否连接？

   ```bash
   ping 192.168.33.1
   ```

3. PLC是否在线？
   - 检查PLC面板指示灯
