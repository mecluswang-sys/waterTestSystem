# 2026-04-15 修改总结

## 一、今日目标

今天主要围绕以下几类问题进行修改与联调：

1. 1号操作台电磁阀1控制链路异常排查与修复。
2. M100.0 地址替代原 Q0.0 / M12.0 逻辑后的统一收口。
3. 测试区、准备区、1号操作台之间的控制冲突与状态刷新冲突消除。
4. 1号操作台流程图 UI 可读性增强。
5. 4-20mA 调压阀能力扩展，为后续新增阀门测试预留。

## 二、核心功能修改

### 1. 电磁阀1 控制地址改为 M100.0

- 将 1号操作台的电磁阀1 控制由原有路径统一切换到 `M100.0`。
- `DeviceManager::setRelay(0, ...)` 与 `getRelayState(0, ...)` 已改为读写 M 区 `M100.0`。
- `S7PLCClient` 新增 `readMerkerBool()` / `writeMerkerBool()`，用于直接访问 S7 Merker 区。
- 相关日志统一增加 `[M100]` 前缀，便于联调定位。

涉及文件：

- `src/DeviceManager.cpp`
- `include/DeviceManager.h`
- `src/S7PLCClient.cpp`
- `include/S7PLCClient.h`

### 2. 1号操作台底部 DQ 按钮区移除

- 删除了 1号操作台下方“继电器输出控制(DQ)”区域的界面挂载。
- 电磁阀1 改为仅通过上方流程图图元控制。
- 状态刷新逻辑改为不依赖底部按钮存在，避免移除面板后影响图元联动。

涉及文件：

- `src/gui/Station1Panel.cpp`

### 3. 图元点击双触发问题修复

本次问题的根因不再按“简单防抖”处理，而是改了触发模型：

- 电磁阀图元从 `selectionChanged` 触发切换，改成 `viewport mouse release + item hit` 单路径触发。
- 电磁阀1 图元关闭 selectable，避免再次进入 `selectionChanged` 路径。
- 保留必要的锁窗口与保护逻辑，防止底层输入重复投递时再次误触发。
- 增加了触发源日志，便于继续定位输入事件问题。

涉及文件：

- `src/gui/Station1Panel.cpp`
- `include/gui/Station1Panel.h`

### 4. 测试区控制冲突处理

- 测试区“电磁阀状态/控制”区域改为只读显示，不再直接写继电器。
- 测试区实时刷新在代码层强制关闭，不再依赖 `ui.enable_test_live_update` 配置项。
- 避免测试区刷新和操作台图元控制对同一位产生竞争或状态回写。

涉及文件：

- `src/gui/TestPanel.cpp`
- `src/gui/MainWindow.cpp`

### 5. 远程模式联动补全

- `StationClient` 增加自动重连定时器与相关日志。
- `MainWindow`、`PreparationPanel`、`TestPanel`、`AutoTestPanel`、`Station1Panel` 等页面补齐 `StationClient` 注入。
- 严格远程模式开启时，Station 端控制统一走主控机转发，不再本地直连 PLC。

涉及文件：

- `src/StationClient.cpp`
- `include/StationClient.h`
- `src/gui/MainWindow.cpp`
- `src/gui/PreparationPanel.cpp`
- `src/gui/TestPanel.cpp`
- `src/gui/AutoTestPanel.cpp`
- `src/gui/Station1Panel.cpp`

## 四、4-20mA 调压阀扩展

### 1. 调压阀数量改为配置化

- 原来 `DeviceManager` 中调压阀数量固定为 2 个。
- 现在改为由 `config/system.conf` 中的 `valve.count` 控制，范围 `[1, 8]`。
- 初始化时按数量动态建立：
  - 调压阀对象
  - PID 实例
  - AO/AI/DI 地址映射
  - 压力反馈量程配置

### 2. 新增 valve.3 配置模板

- 在配置文件中补充了 `valve.3.*` 模板。
- 后续若需测试第 3 个 4-20mA 阀，只需：
  1. 将 `valve.count` 改为 `3`
  2. 修改 `valve.3.ao.byte_offset` 等现场地址
  3. 重启程序

涉及文件：

- `src/DeviceManager.cpp`
- `include/DeviceManager.h`
- `config/system.conf`
