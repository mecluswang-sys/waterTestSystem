# 🖥️ 主控台（Terminal Server）界面设计方案

## 📋 需求分析

### 主控台的核心职责

```
Terminal Server 主要功能:
├─ 连接和管理1台PLC (S7-1200)
├─ 实时采集传感器数据 (4压力+4温度+流量+时间戳)
├─ 通过TCP:5555向4个Station广播数据
├─ 接收来自Station的控制命令
├─ 管理4个Station的连接状态
└─ 保存数据日志和系统日志
```

### 主控台用户

```
操作员: 中央控制室操作人员
  • 需要查看PLC连接状态
  • 需要了解各Station的状态
  • 需要手动发送控制命令 (紧急情况)
  • 需要查看实时数据汇总
  • 需要配置系统参数

维护人员: 系统维护和调试人员
  • 需要诊断网络连接问题
  • 需要查看系统日志
  • 需要手动重启服务
  • 需要监控系统性能
  • 需要检查数据完整性
```
