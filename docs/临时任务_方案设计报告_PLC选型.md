## B. 摘要

本方案采用“PLC现场控制 + Terminal集中采集/分发 + Station可视化操作”的分层结构。针对当前需求（压力/温度/流量采集，阀泵控制，报警追溯，后续多站扩展），推荐PLC主选 Siemens S7-1200 CPU 1215C，备选1214C。

本方案的关键落地点:

1. 压力采集基线固定为 DB6 结构化读取（MainValue_Real，偏移46，步长108）。
2. 采集周期 100 ms，界面更新 200 ms。
3. 所有控制命令“写后回读确认”，失败进入告警与降级。
4. 引入DB版本校验，规避PLC程序变更导致的地址错读。

## D. 需求定义

### D.1 功能需求

1. 实时采集压力、温度、流量关键过程量。
2. 支持阀门、泵、调压执行机构控制。
3. 支持报警分级、日志记录、测试追溯。
4. 支持多操作台并发显示与受控操作。

### D.2 性能需求

1. PLC数据采集周期: 100 ms。
2. HMI显示刷新周期: <= 200 ms。
3. 控制命令端到端响应: <= 300 ms。
4. 连续稳定运行: >= 72小时。

### D.3 可靠性需求

1. PLC失联检测时限: 3秒。
2. 自动重连周期: 1秒。
3. 恢复后采集重建时限: <= 10秒。

### D.4 可维护性需求

1. 地址映射配置化。
2. DB版本可校验。
3. 日志可追溯到命令与反馈。

## F. 总体架构设计

### F.1 分层架构

1. 现场层: 传感器/阀门/泵 + PLC
2. 站控层: Terminal（采集、处理、转发）
3. 交互层: Station（显示与操作）

### F.2 数据流

1. PLC更新DB。
2. Terminal按100 ms轮询DB。
3. Terminal向Station广播过程量。
4. Station发控制命令到Terminal。
5. Terminal写PLC并回读反馈，返回执行结果。

### F.3 控制流

- 控制入口统一经Terminal，不允许Station直接写PLC。
- 控制执行必须包含互锁判断与回读确认。

## G. PLC选型设计

### G.1 候选型号

- S7-1200 CPU 1212C
- S7-1200 CPU 1214C
- S7-1200 CPU 1215C
- S7-1500入门型号

### G.2 对比维度

- 性能余量
- 扩展能力
- 通信并发能力
- 成本与供货稳定性
- 与现有系统改造成本

### G.3 选型评分（定性）

| 型号 | 性能 | 扩展 | 成本 | 改造成本 | 综合结论 |
|---|---|---|---|---|---|
| 1212C | 低 | 中低 | 优 | 优 | 不建议主选 |
| 1214C | 中 | 中高 | 良 | 优 | 备选 |
| 1215C | 高 | 高 | 良 | 优 | 主选 |
| 1500入门 | 很高 | 很高 | 一般 | 中 | 当前超配 |

### G.4 选型结论

- 主选: S7-1200 CPU 1215C
- 备选: S7-1200 CPU 1214C

理由:

1. 满足一期并兼顾二期扩展。
2. 与Snap7方案兼容，风险低。
3. 供货与维护复杂度可控。

## J. DB与地址映射设计

### J.1 DB分工建议

- DB6: 传感器结构区（压力/温度）
- DB2: 流量区
- DB3: 阀门区
- DB4: 泵区
- DB5: 系统状态区

### J.2 压力映射规范

读取表达式:
offset = base_offset + (sensor_id - 1) * item_size + main_value_real_offset

当前参数:

- base_offset = 0
- item_size = 108
- main_value_real_offset = 46

当前地址:

- PS1 -> DB6.DBD46
- PS2 -> DB6.DBD154
- PS3 -> DB6.DBD262

### J.3 单位与缩放

- 当前策略: 读取MainValue_Real原值（scale=1）
- 若后续切换单位，优先通过配置变更，不改核心代码路径

### J.4 DB版本一致性

PLC中增加:

- DB_VERSION
- DB_LAYOUT_ID

上位机规则:

- 启动校验版本
- 不一致时禁止写控制，仅保留只读并告警

## K. 控制、安全与故障处理设计

### K.1 控制联锁

1. 泵启动前检查关键阀位。
2. 调压动作期间禁止冲突命令并发。
3. 急停触发后输出转入安全态。

### K.2 告警分级

- A级: 急停、主通信中断、关键联锁失效
- B级: 越限、动作超时
- C级: 一般通信波动、非关键异常

### K.3 故障降级

- PLC失联超过3秒 -> 系统只读 + 告警
- 重连间隔1秒
- 连续失败30次 -> 提示人工介入

### K.4 日志追溯

记录字段至少包含:

- 时间戳
- 设备ID
- 命令类型
- 命令参数
- 回读结果
- 操作者ID
