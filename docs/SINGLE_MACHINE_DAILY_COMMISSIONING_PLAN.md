# 单机阶段（日常）联调执行计划表

适用范围：当前仅有工控机 + PLC + 少量操作台（未上齐 4 台平板）阶段。

目标：用最小成本持续验证 Terminal-Station 架构稳定性，防止回归。

## 1. 每日执行节奏

- 执行频次：每日 1 次（建议班前或收工前固定时段）。
- 执行时长：30-45 分钟。
- 记录位置：
  - 联调日志模板：`docs/TERMINAL_STATION_COMMISSIONING_LOG_TEMPLATE.md`
  - 故障定位表：`docs/FAULT_DIAGNOSIS_THREE_STAGE.md`

## 2. 每日最小回归集（必须项）

### A. 启动与连接（约 5 分钟）

1. 启动 Terminal（工控机）。
2. 确认 PLC 连接成功、采集线程启动。
3. 启动至少 1 个 Station，确认“已连接到主控台”。
4. 确认严格远程模式开启：`station.strict_remote_mode = true`。

通过标准：4 步全部成功。

### B. 数据链路（约 8 分钟）

1. 在实时监控页确认压力/流量持续刷新。
2. 切换页面 3 次（准备区 -> 测试区 -> 1号操作台 -> 返回），观察是否冻结。
3. 保持页面 2 分钟，观察是否出现明显抖动或停止刷新。

通过标准：无冻结、无明显卡死、数据持续变化（或按现场状态稳定）。

### C. 控制链路（约 12 分钟）

按顺序执行以下动作，每项至少 1 次：

1. 准备区：加水开始 -> 停止。
2. 准备区：泄压阀开 -> 关。
3. 测试区：开始测试 -> 停止测试。
4. 测试区：紧急停止。
5. 1号操作台：阀门弹窗开/关。
6. 1号操作台：DQ 继电器切换（非泵位）。
7. 自动测试区：待测阀开 -> 关。

通过标准：每次操作均可在 Terminal 侧观察到命令执行，且 UI 状态回显正确。

### D. 断线恢复（约 8 分钟）

1. 手动关闭 Station 进程。
2. 重新启动 Station 并重连。
3. 复测一个控制动作（建议“测试区开始测试”）。

通过标准：重连成功，控制链路恢复。

## 3. 每周增强回归（建议每周 2 次）

1. 连续重连压力测试：20-30 次断开重连循环。
2. 连续运行测试：60 分钟不间断运行，统计刷新/控制异常次数。
3. 异常注入：
   - 临时断开 PLC 网络后恢复，观察恢复时间。
   - 临时停止 Terminal 后恢复，观察 Station 重连表现。

## 4. 失败处理流程（强制）

任一必须项失败时，必须执行：

1. 立即使用三段式定位：A（命令发出）/B（主控执行）/C（PLC反馈）。
2. 在联调日志中登记：时间、复现步骤、影响范围、临时处置。
3. 当天未闭环的问题，纳入次日优先处理清单。

## 6. 退出单机阶段的判定门槛

连续 5 个工作日满足以下条件，才建议进入“多平板阶段”：

1. 每日最小回归集通过率 100%。
2. 无阻断级故障（无法控制或数据持续中断）。
3. 重连恢复成功率 >= 95%。
4. 控制链路闭环成功率 >= 99%。
