# 压力传感器缓冲区结构（替代 UDT）

版本: 2026-04-01

## 1. 结论

当前 PLC 到上位机的压力链路不再使用 UDT 映射。
PLC 仅负责把 Modbus 采集结果写入 DB1 连续缓冲区，上位机按固定偏移解析。

## 2. 布局规则

1. 每个传感器占 17 个 WORD。
2. 每个传感器步长: 34 字节。
3. 1/2/3 号传感器解析公式:
   - itemBase = base_offset + (sensor_id - 1) * 34
   - lowWordOffset = itemBase + 2 * 2
   - highWordOffset = itemBase + 3 * 2
4. 压力相关字段:
   - word[2] = 低16位
   - word[3] = 高16位
   - MainValue float32 = (high << 16) | low
   - word[9] = 单位码（HART 单位表）
   - word[11] = 显示小数位
   - word[13]/word[14] = Offset float（低/高16位）
   - word[15]/word[16] = Gain float（低/高16位）

5. 当前上位机计算顺序:
   - raw = MainValue
   - calibrated = raw * Gain + Offset
   - 按 word[9] 对应的 HART 单位换算到 kPa
   - 显示时按 word[11] 控制小数位

## 3. 当前项目配置

对应 [config/system.conf](config/system.conf):

- db.sensor.number = 1
- db.sensor.base_offset = 119
- db.sensor.item_size = 34
- db.sensor.main_value_float.low_word_index = 2
- db.sensor.main_value_float.high_word_index = 3
- pressure.count = 3

## 4. 日志关键字段

在 [build/bin/Debug/deploy/logs/pressure_device_debug.log](build/bin/Debug/deploy/logs/pressure_device_debug.log) 中关注:

- [DEVICE][PRESSURE][BUFFER]
- lowWordIndex / highWordIndex
- rawWords
- rawReal

若 rawWords 长期固定(例如 0x0000,0x0C00)，说明 PLC 缓冲区该位置未写入实时压力。
