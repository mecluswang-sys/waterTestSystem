# 🖥️ 工业平板硬件规格需求分析

## 📋 应用需求分析

### WaterTestSystem 应用特点

```
单个Station进程的资源占用:
├─ 二进制大小: 325KB (可执行文件)
├─ 内存占用: 50-80MB (运行时)
├─ CPU占用: 5-15% (1核)
├─ 网络带宽: 10Kbps (TCP:5555)
├─ 磁盘I/O: 低
└─ 实时性要求: 中等 (100ms周期可接受)

系统特点:
• 基于Qt6 (图形界面框架)
• 网络客户端模式 (连接Terminal Server)
• 数据实时显示 (曲线图、数据表)
• 触屏交互 (点击、滑动、长按)
└─ 关键指标: 触屏响应延迟 <200ms
```

## 📈 **性能数据详细分析**

### 应用启动时间

```
Windows 10/11启动: 15-20秒

WaterTestSystem.exe启动:
• Station模式加载: 2-3秒
  ├─ 加载Qt库: 1秒
  ├─ 初始化GUI: 1秒
  ├─ 连接Terminal服务器: 1秒
  └─ 显示首个数据: <1秒

总启动时间: 6-8秒 (从点击图标到显示数据)
```

### 实时运行占用

```
单个Station进程 (i5+8GB配置):

内存占用:
  ├─ 基础占用: 50MB (进程启动)
  ├─ 加载界面: +20MB (GUI渲染)
  ├─ 显示曲线: +30MB (数据缓存)
  └─ 总占用: 80-100MB (占比1.2-1.5%)

CPU占用:
  ├─ 待机时: 2-3% (心跳保活)
  ├─ 更新曲线: 8-12% (单核)
  ├─ 数据写入: 5-8% (单核)
  └─ 触屏交互: 3-5% (单核)
  平均占用: 10% (一个核心)
```

### 多应用场景

```
运行4个Station (同一PC上):

总内存占用: 400MB (占总8GB的5%)
总CPU占用: 25-40% (4个核心分摊)
网络带宽: 40Kbps (4×10Kbps)
磁盘I/O: 很低 (<1MB/s)

结论: ✅ 完全无压力
```

### 网络性能

```
TCP连接到Terminal Server (localhost:5555):

延迟: <1ms (本地网络)
带宽占用: 10Kbps (约1.3KB/秒)
  ├─ 每100ms一次数据包: 1KB
  ├─ 心跳包(每5秒): 50B
  └─ 控制命令(可变): 50-500B

网络占用: <0.1% (千兆网络)
```

## 🔍 **详细规格选择指南**

### CPU选择

#### ❌ 避免

```
❌ Pentium / Celeron
   • 太弱 (单线程性能不足)
   • 不适合GUI应用

❌ ARM处理器 (Snapdragon/MediaTek)
   • 软件兼容性问题
   • Windows驱动有限
   • 不推荐

❌ 低端Atom/N100
   • 性能太弱
   • 触屏反应慢
```

#### ✅ 推荐

```
✅ Intel Core i5 第11代以上
   • i5-1135G7 (11代, 4P+4E, 3.0GHz)
   • i5-1235U (12代, 2P+10E, 3.3GHz)
   • i5-1335U (13代, 2P+10E, 3.4GHz)

✅ AMD Ryzen 5 / 7 (5000系列+)
   • Ryzen 5 5500U (8核, 2.1-4.0GHz)
   • Ryzen 7 5700U (8核, 1.8-4.3GHz)

性能等级排序:
  最佳: i5-1335U (最新)
  推荐: i5-1235U (性价比好)
  可用: i5-1135G7 (性能充足)
```

### 内存选择

#### ❌ 避免

```
❌ 4GB内存
   • 运行单个Station时占用70-90%
   • 不能同时运行其他应用
   • 工业环境易出现故障
```

#### ✅ 推荐

```
✅ 8GB LPDDR4x (标准推荐)
   • 运行Station占用占比20-30%
   • 可同时运行5-10个应用
   • 足以应对大多数场景
   • 价格合理

✅ 16GB LPDDR5 (高端选择)
   • 运行占用只有10-15%
   • 可同时运行20+应用
   • 用于高负载场景
   • 价格贵50-60%
```

**选择建议**: **8GB足够** ✅

### 存储选择

#### ❌ 避免

```
❌ eMMC 64GB
   • 速度慢 (读100MB/s, 写50MB/s)
   • 容量小
   • 工业环保不佳
```

#### ✅ 推荐

```
✅ SSD 256GB
   • 速度快 (读500MB/s+, 写300MB/s+)
   • 容量足够
   • 工业环保好
   • 标准配置

✅ SSD 512GB
   • 容量更大
   • 用于需要本地存储大量数据场景
   • 价格增加不多 (+200-300元)
```

**选择建议**: **256GB SSD** ✅

### 屏幕选择

#### 分辨率

```
❌ 低端: 1024×600, 1280×720
   • 显示不清楚
   • 触屏操作区域小

✅ 标准: 1920×1200 (推荐)
   • 清晰度好
   • 显示数据多
   • 触屏操作舒适

✅ 高端: 2560×1440+
   • 显示效果最佳
   • 对本项目过度
```

#### 屏幕尺寸

```
10寸 (1920×1200)
  ✅ 适合: 工作台操作, 近距离
  ❌ 缺点: 字体可能偏小

13-15寸 (1920×1200+)
  ✅ 优点: 显示内容多, 操作舒适
  ❌ 缺点: 重量增加, 价格贵
  ⚠️ 建议: 如果工作台宽敞可考虑
```

**选择建议**: **10寸 1920×1200** ✅

### 防护等级选择

```
IP54 (防溅)
  • 水溅不影响正常运行
  • 我们的工作环境足够
  • 成本适中
  ✅ 推荐

IP55 (防喷水)
  • 可抵抗喷枪冲洗
  • 适用更恶劣环境
  • 成本增加不多 (+300元)

IP65 (防尘防水)
  • 完全防尘防水
  • 极端工业环境
  • 对本项目过度
  ❌ 不推荐
```

**选择建议**: **IP54** ✅
