文档编号: WTS-IO-LIST-20260318
版本: v1.0
日期: 2026-03-18
适用范围: 一期联调（3路压力 + 3路温度 + 阀泵控制）

---

## 1. 说明

本表用于电气设计、PLC程序点位落地和上位机联调统一基准。

字段说明:

- 点号: 系统唯一编号
- 信号名: 工艺名称
- 类型: AI/AO/DI/DO
- PLC地址: 建议地址（最终以电气图和TIA项目为准）
- 端子号: 建议端子（最终以端子排图为准）
- 量程/单位: 工程范围
- 采样/动作周期: 刷新或控制周期
- 备注: 联锁、告警、用途说明

## 5. 联锁与验收要点

1. 泵启动联锁: 关键阀位未满足时禁止启动。
2. 写后回读: 所有DO命令必须在300 ms内回读到有效反馈。
3. 急停逻辑: 急停触发时，所有危险DO必须进入安全态。
4. 点表冻结: 本文冻结为v1.0，后续变更必须走变更单。
