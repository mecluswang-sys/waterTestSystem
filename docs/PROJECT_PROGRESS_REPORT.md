## 项目背景

将现有单机PC+PLC的水质测试系统升级为**Terminal-Station分布式架构**，支持：

- 1个中央PC (Terminal) 管理PLC
- 4个工业平板 (Station) 同时操作
- 实时数据共享和远程控制
- 10米远距离通讯
