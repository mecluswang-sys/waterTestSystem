# 水用电磁阀测试设备需求规格书 V1.0（草案）

## 1. 文档目的

将《需求2——水用电磁阀测试设备方案（附带气检和吹气）》从“方案描述”升级为可执行、可验收、可追溯的工程规格书，作为设计、开发、联调、验收的统一基线。

## 2. 适用范围

- 设备对象：水用电磁阀
- 口径范围：DN15-DN200
- 测试介质：水介质、空气介质
- 功能范围：手动测试、寿命测试、气检、吹气、自动泄压、日志追溯
- 工位范围：夹装测试工位 >= 2，开放式寿命测试工位 >= 1

## 3. 术语与统一写法

- 压力单位统一使用 `kgf/cm^2`（内部存储允许保留 kPa）
- “泄露”统一写作“泄漏”
- 开阀判定：通过压力变化量与时间窗判定阀芯动作有效
- 泄漏判定：通过量化指标判定，不采用纯人工观察作为唯一标准

## 4. 总体功能要求

1. 开机后必须进行气介质自检，验证管路密封性与关键部件状态。
2. 支持水介质开阀性能测试与空气介质密封测试（高压/低压）。
3. 支持测试后吹气排液，确保阀腔内残液可控。
4. 支持寿命测试（仅水介质），测试完成或异常后自动泄压并记录循环次数。
5. 测试中断或结束时，系统自动切断水源/气源并排空管路。
6. 具备急停、漏电保护、联锁保护、防夹保护。
7. 显示系统需给出关键寿命件剩余寿命与更换提醒。

## 5. 设备与工艺约束

### 5.1 压力与耐压

- 测试压力范围：0-25.5 kgf/cm^2
- 管路、接口、检测元件最低耐压：>= 81.6 kgf/cm^2
- 要求提供耐压校核表（部件型号、额定耐压、安全系数）

### 5.2 供电

- DC：6-36 V 可调
- AC：0-280 V 可调
- 必须包含漏电保护、过流保护、短路保护

### 5.3 介质与过滤

- 水介质过滤建议：100目左右
- 空气介质过滤建议：300目左右
- 进压口与回水槽需配置可拆卸过滤器

### 5.4 管路与工位

- 主液体管路：DN100
- 测试管路应支持通径切换装置
- 工位相互独立，任一工位故障不影响其他工位

## 6. 测试流程规格（状态机定义）

### 6.1 状态定义

- IDLE：待机
- SELF_CHECK_GAS：气介质自检
- CLAMP_READY：夹装确认
- PRESSURE_BUILD：建压
- WATER_OPEN_TEST：水介质开阀测试
- MEDIA_SWITCH：水气切换
- AIR_OPEN_TEST：空气介质开阀动作测试
- AIR_LEAK_TEST：空气介质泄漏测试
- BLOW_PURGE：吹气排液
- DEPRESSURE：泄压
- FINISH：测试完成
- FAULT_STOP：故障停机
- EMERGENCY_STOP：急停停机

### 6.2 状态转移要求

- 任意状态触发急停 -> EMERGENCY_STOP（最高优先级）
- 任意状态关键传感器失效 -> FAULT_STOP
- MEDIA_SWITCH 失败 -> FAULT_STOP
- FINISH/FAULT_STOP/EMERGENCY_STOP 均必须进入 DEPRESSURE 后回到 IDLE

## 7. 判定算法与参数（初版建议值）

> 说明：以下为联调初始值，必须通过现场标定后冻结版本。

### 7.1 开阀动作判定

- 采样周期：100 ms
- 观测窗口：2.0 s
- 最小有效压降阈值：
  - DN15-DN50：>= 0.082 kgf/cm^2
  - DN65-DN100：>= 0.122 kgf/cm^2
  - DN125-DN200：>= 0.184 kgf/cm^2
- 判定条件：
  - 在观测窗口内压降量达到阈值 -> 开阀动作有效
  - 超时未达到阈值 -> 开阀动作无效

### 7.2 泄漏判定（空气介质）

- 高压档保压时间：5 s
- 低压档保压时间：5 s
- 判定指标（二选一或并行）：
  - 压力衰减法：单位时间压降率 <= 阈值
  - 流量法：稳态泄漏流量 <= 阈值
- 初始建议阈值：
  - 高压档压降率 <= 0.031 kgf/cm^2/s
  - 低压档压降率 <= 0.020 kgf/cm^2/s
- 人工观察气泡仅作为辅助，不作为唯一判定依据

### 7.3 吹气排液判定

- 吹气持续时间：3-8 s（按型号可配置）
- 吹气后允许残液判定：以腔体压力恢复曲线与动作重复性为准

## 8. 手动测试与寿命测试要求

### 8.1 手动测试

1. 夹装确认
2. 建压至设定范围
3. 水介质开阀测试
4. 切换空气介质
5. 空气介质开阀动作与高/低压泄漏测试
6. 吹气排液
7. 自动泄压
8. 输出结果并允许下料

### 8.2 寿命测试

1. 夹装确认
2. 建压至设定范围
3. 自动循环动作（仅水介质）
4. 达到目标循环数或不合格即停止
5. 自动泄压
6. 记录循环次数、异常代码、停止原因

## 9. 联锁与安全要求

1. 急停触发后，所有输出置安全位，执行泄压流程。
2. 防夹信号触发时，夹装机构停止并报警，不允许进入建压。
3. 漏电保护触发时，禁止继续测试并记录事件。
4. 水气切换阀与主供压阀必须联锁，防止误混介质。
5. 压力超限、传感器异常、执行器超时均触发故障停机。

## 10. HMI与分控台要求

### 10.1 主控制面板

- 显示屏
- 电压/电流显示
- 指示灯（运行、故障、急停、介质状态）
- 急停按钮

### 10.2 分控台

- 实体按钮（开始、停止、复位、急停）
- 高压/低压两路气源控制
- 状态反馈灯

### 10.3 显示与日志

- 显示实时压力、流量、阀状态、当前步骤
- 显示寿命件剩余寿命与更换提醒
- 记录每次测试完整过程与判定结果

## 11. 数据记录与追溯字段

每条测试记录至少包含：

- 时间戳
- 工位号
- 产品型号/口径
- 测试配方版本
- 水介质开阀判定结果
- 空气高压/低压泄漏判定结果
- 吹气执行结果
- 总结论（PASS/FAIL）
- 失败原因代码
- 操作员与设备编号

## 12. 验收标准（建议）

### 12.1 功能验收

- 手动测试全流程可执行并形成结果
- 寿命测试可自动运行、自动停止、自动泄压
- 异常触发可进入故障流程并保留日志

### 12.2 性能验收

- 状态刷新周期 <= 200 ms
- 指令响应 <= 500 ms
- 压力采样周期 <= 100 ms

### 12.3 安全验收

- 急停动作闭锁有效
- 漏电保护有效
- 超压联锁有效
- 防夹联锁有效

### 12.4 可靠性验收

- 连续运行 24 h 无死机
- 中断恢复后可继续下一轮测试

## 13. 交付与资料要求

供应方/集成方需交付：

1. 元件清单（BOM）
2. 关键元件参数表（耐压、精度、厂家、型号）
3. 电气原理图与接线图
4. 管路图与阀岛图
5. 控制逻辑说明书
6. 维护保养说明
7. 故障码说明
8. 验收测试报告

## 14. 未决事项（需评审确认）

1. 泄漏判定最终采用压降法、流量法，还是双通道并判。
2. 吹气排液的合格判据是否需要单独传感器。
3. DN 分段阈值是否按产品族进一步细分。
4. 高压/低压的具体设定点与容差范围。
5. 工位并发上限与节拍目标。
